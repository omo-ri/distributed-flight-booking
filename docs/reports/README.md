## 复盘文档

四项必备内容（blameless、时间线、量化影响、可执行行动项、假设与现实的差异）见 [`CLAUDE.md`](../../CLAUDE.md) § 3。

其中**假设与现实的差异**是演练报告里最有价值的部分。"我以为熔断器 5 秒内打开，实际用了 47 秒，因为窗口计数有个边界问题" —— 这种记录才说明演练真的做了。行动项要能落地：每条对应一个 [`tasks/`](../tasks/README.md) 条目，"以后小心点"不是行动项。

演练的完整执行流程（写假设 → 注入 → 观测 → 恢复 → 对比 → 复盘 → 落实行动项 → 重新演练）见 [roadmap.md 阶段 5](../plans/roadmap.md)。

## 压测报告要求

- 记清楚**测试条件**：负载模型、时长、环境、镜像版本。条件不明的数字无法比较
- 同时记 **SLI 判定** 和 **k6 客户端侧原始数据** —— 两边口径不同，差异本身有信息量
- **异常必须写下来**，即使判定是 PASS。分位数按设计就会隐藏尾部
- 明确写出这份数据**不能**回答什么问题
